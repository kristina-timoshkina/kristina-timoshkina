## Мои проекты

### Инструменты для DaVinci Resolve / Fusion

Коммерческий проект по созданию и доработке пользовательских инструментов для DaVinci Resolve / Fusion.

В рамках проекта я работала с логикой интерфейса, параметрами управления, структурой .setting-инструментов, тестированием поведения эффектов и доработкой функций под требования заказчика.

Один из реализованных инструментов — LUT Master для работы с LUT и цветокоррекцией. В нём были реализованы выбор и смешивание LUT, управление интенсивностью эффекта, tonal limits, texture-контролы, LUT protection, режимы просмотра результата и работа с цветовыми пространствами.

Также был создан Universal Animator с управлением Position, Scale и Rotation.

В разработке использовала AI-assisted подход с ChatGPT / Codex: формулировала требования, проверяла структуру и логику, тестировала результат непосредственно в DaVinci Resolve и дорабатывала инструмент до рабочего состояния.

Проект выполнен для реального заказчика и оплачен.

### Telegram-бот для поиска вакансий

Бот помогает собирать, хранить и показывать подходящие вакансии. В проекте реализованы пользовательский режим, административные команды, база данных, ежедневная подборка и AI-анализ вакансий.

### Telegram-бот для информационного проекта

Бот помогает пользователям получать структурированную информацию через понятное меню, а администратору — управлять содержимым проекта.
